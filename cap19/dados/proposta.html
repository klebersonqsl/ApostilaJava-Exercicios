Proposta de treinamento em Java

Curso presencial de 80 horas · turma de novembro de 2026

Esta proposta apresenta o conteúdo, a carga horária e os resultados esperados do treinamento em Java, do básico ao avançado, voltado para a equipe de desenvolvimento.

1. Objetivos

Ao final do curso, cada participante será capaz de:

  • escrever programas em Java usando orientação a objetos, coleções e tratamento de erros;
  • ler e gravar arquivos de texto, XML e JSON;
  • acessar bancos de dados MySQL, PostgreSQL, Firebird, SQLite e SQL Server;
  • construir telas desktop com Swing e JavaFX;
  • desenvolver aplicações web com Servlets, JSP, JSF e Spring Boot.

3. Metodologia

As aulas combinam explicação curta e muita prática. Cada assunto é apresentado com um exemplo completo, que os participantes digitam, executam e modificam. Ao fim de cada módulo há uma lista de exercícios e, no último dia, um projeto final em grupo, com apresentação para a equipe.

O material de apoio é a Apostila de Java, com um arquivo por capítulo, exemplos executáveis e as telas de cada programa. Todo o código-fonte é entregue aos participantes.

4. Requisitos

Computadores com o JDK 21 ou 25, uma IDE (NetBeans, IntelliJ IDEA ou Eclipse), o Maven e acesso aos servidores de banco de dados da empresa. Conhecimentos prévios de programação ajudam, mas não são obrigatórios.

5. Investimento e prazos

O treinamento será realizado em quatro semanas, com cinco encontros semanais de quatro horas. O cronograma detalhado será enviado após a aprovação desta proposta, junto com a lista de participantes e o local das aulas.

Permanecemos à disposição para ajustar o conteúdo às necessidades da equipe, incluindo módulos extras sobre testes automatizados, segurança de aplicações ou APIs REST.
